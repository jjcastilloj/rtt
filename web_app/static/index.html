The NIST SP 800-22 Statistical Test Suite is a comprehensive set of statistical tests designed to evaluate the randomness of binary sequences. These tests help assess whether a random number generator produces output that is statistically random and suitable for cryptographic applications.

The use of this tool does not guarantee that a sequence is random or that a random number generator is of high quality. The use of this tool and the interpretation of its results is entirely the responsibility of the user.
