# Testing Documentation

## Statistical Tests Overview

### 1. Frequency Test
- Purpose: Tests the proportion of ones and zeros
- Parameters: None
- Interpretation: P-value > 0.01 for randomness

### 2. Block Frequency Test
- Purpose: Tests frequency within blocks
- Parameters: Block size
- Analysis: Chi-square distribution

### 3. Runs Test
- Purpose: Tests oscillation between zeros and ones
- Parameters: None
- Analysis: Total number of runs
